'@openchoreo/genui-react': minor
---

Add `@openchoreo/genui-react`, the React renderer for the constrained
Generative UI engine. It draws a widget's view model with the design-system bar,
pie and line charts and single-number card, and shows a plain-language
explanation when something cannot be drawn. It has no OpenChoreo-specific data
access, so other dashboards can reuse it.
