Add a `MetricCard` component that shows one headline number with a label and
an optional caption. Values can be shown as a plain number, a percentage (from
a fraction) or a duration (from seconds), and a missing value shows a dash with
a screen-reader "No data" note. It makes no API calls and has no OpenChoreo
dependency.
