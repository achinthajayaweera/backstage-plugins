'@openchoreo/genui-core': minor
---

Add `@openchoreo/genui-core`, the framework-agnostic core of the constrained
Generative UI engine: the widget spec schema, catalog validation, a closed set
of safe data transforms, and a multi-source fetch pipeline with row, call and
namespace caps. It has no React or Backstage dependency so other dashboards can
reuse it.
